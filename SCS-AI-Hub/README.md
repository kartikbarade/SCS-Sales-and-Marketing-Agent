# SCS AI Hub — Final Year Project

Starter folder scaffold for the SCS AI-Powered QMS & ISO Consultancy project.

## Planned stack
- Frontend: React, Vite, JavaScript, Tailwind CSS
- Backend: FastAPI, Python 3.11+
- Database: MySQL + SQLAlchemy
- AI: LangChain / LangGraph, an LLM provider, RAG, ChromaDB

## Development roadmap
1. Environment setup and verify tools
2. Create and run the React frontend
3. Configure Tailwind and React Router
4. Recreate the SCS public home page from the supplied screenshot
5. Add chatbot UI
6. Create FastAPI app and health endpoint
7. Connect MySQL and create database models
8. Implement owner authentication and protected routes
9. Build dashboard and management pages
10. Add AI chatbot, agent routing, and RAG knowledge base
11. Add tests, documentation, and deployment

## Important
This ZIP is a project scaffold, not a complete working application yet. Placeholder files are intentionally provided so we can implement each level step by step. Do not put API keys in frontend code. Keep secrets in local `.env` files and do not commit them.
